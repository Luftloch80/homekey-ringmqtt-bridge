    TypKennungNameAktivBenutzt

    MQTT-Broker

    Derselbe Broker, an den auch HomeKey-ESP32 angeschlossen ist.

    HomeKey-ESP32

    Die Geraete/Client-ID aus der MQTT-Konfiguration deines HomeKey-ESP32 (Web-UI → Settings → MQTT). Topics werden daraus automatisch abgeleitet, koennen bei Bedarf aber ueberschrieben werden.

    Ring-Intercom

    Die Bridge spricht direkt mit der Ring Cloud API - ein separat laufendes ring-mqtt wird nicht mehr benoetigt. Konto und Geraet werden weiter unten eingerichtet.

    Zugriff

    Ring-Konto

    Einmaliger Login mit deinem Ring-Account. Der Zugriffstoken wird danach automatisch erneuert - Zugangsdaten selbst werden nicht gespeichert.
